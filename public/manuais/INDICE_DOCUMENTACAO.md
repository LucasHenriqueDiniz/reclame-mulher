## 💾 Armazenamento e Versionamento

### Recomendações de Armazenamento

```
Repositório Git:
├─ LEIA_ME_PRIMEIRO.md (sempre atualizar)
├─ MANUAL_PLATAFORMA.md (versionar mudanças)
├─ MANUAL_PLATAFORMA.html (opcional, regenerar se mudar MD)
├─ FLUXOS_VISUAIS.md (versionar com arquitetura)
├─ GUIA_RAPIDO.md (sempre atualizar)
└─ INDICE_DOCUMENTACAO.md (este arquivo)

Servidor de Documentação (se houver):
├─ MANUAL_PLATAFORMA.html (principal)
└─ GUIA_RAPIDO.md (destacado)

Wiki Interna (Confluence/NotionWiki):
├─ MANUAL_PLATAFORMA.md (com versioning)
└─ FLUXOS_VISUAIS.md (com ilustrações)

Repositório de Ajuda (Help Center):
└─ GUIA_RAPIDO.md (seções estruturadas)
```

### Estratégia de Versioning

**Tag Git para cada atualização:**
```bash
git tag -a v1.0-docs "Documentação inicial da plataforma"
git tag -a v1.1-docs "Atualizado com novos fluxos"
# ... conforme atualizações de produto
```

**Changelog em LEIA_ME_PRIMEIRO.md:**
```markdown
### Changelog
- **v1.0 (2025-01-XX)**: Documentação inicial completa
- **v1.1 (2025-02-XX)**: Adicionado fluxo X, atualizado Y
```
